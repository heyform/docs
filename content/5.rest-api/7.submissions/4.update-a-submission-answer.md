---
title: "Update a submission answer"
description: "Set an answer for a published question. The value must pass that question’s validation."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/forms/{formId}/submissions/{submissionId}/answer"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `submissions:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

::field{name="submissionId" type="string" :required="true"}
The 24-character hexadecimal submission ID. See [SubmissionModel][submission-model].
::

## Request body

`application/json`

::field{name="fieldId" type="string" :required="true"}
ID of a published question. See [FormField][field-model].
::

::field{name="value" type="AnswerValue" :required="true"}
The answer value for the field’s type. See [AnswerValue][answer-value-model].
::

## Response

**200** · `application/json`

Source model: [SubmissionModel][submission-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `updated` | `boolean` | Whether the update succeeded. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/submissions/${SUBMISSION_ID}/answer" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "fieldId": "question1",
  "value": "Add keyboard shortcuts"
}'
```

```json [200 response]
{
  "id": "507f1f77bcf86cd799439015",
  "updated": true
}
```
