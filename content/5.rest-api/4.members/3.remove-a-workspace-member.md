---
title: "Remove a workspace member"
description: "Remove a user from the workspace and its projects. Only the workspace owner can remove members, and the owner cannot be removed."
apiReference: true
---

::api-reference{method="DELETE" path="/api/v1/workspaces/{workspaceId}/members/{userId}"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `members:write` scope.
::

## Path parameters

::field{name="workspaceId" type="string" :required="true"}
Workspace ID. See [TeamModel][workspace-model].
::

::field{name="userId" type="string" :required="true"}
User ID. See [UserModel][user-model].
::

## Response

**200** · `application/json`

Source model: [TeamMemberModel][member-model].

| Field | Type | Description |
| --- | --- | --- |
| `removed` | `boolean` | Whether the membership was removed. |
| `workspaceId` | `string` | Workspace ID. |
| `userId` | `string` | User ID. |

#examples

```bash [cURL]
curl --fail-with-body --request DELETE \
  --url "${HEYFORM_URL}/api/v1/workspaces/${WORKSPACE_ID}/members/${USER_ID}" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [200 response]
{
  "removed": true,
  "workspaceId": "wK4s8aP2",
  "userId": "507f1f77bcf86cd799439013"
}
```
