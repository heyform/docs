---
title: "Invite workspace members"
description: "Email the workspace invitation link to up to 20 addresses. Only the workspace owner can invite members. Addresses that already belong to members are skipped."
apiReference: true
---

::api-reference{method="POST" path="/api/v1/workspaces/{workspaceId}/invitations"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `members:write` scope.
::

## Path parameters

::field{name="workspaceId" type="string" :required="true"}
Workspace ID. See [TeamModel][workspace-model].
::

## Request body

`application/json`

::field{name="emails" type="string[]" :required="true"}
1–20 email addresses. Invitees join the workspace when they follow the link in the email.
::

## Response

**201** · `application/json`

| Field | Type | Description |
| --- | --- | --- |
| `workspaceId` | `string` | Workspace ID. |
| `emails` | `string[]` | Lowercased addresses that were sent an invitation. |

#examples

```bash [cURL]
curl --fail-with-body --request POST \
  --url "${HEYFORM_URL}/api/v1/workspaces/${WORKSPACE_ID}/invitations" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "emails": ["ada@example.com"]
}'
```

```json [201 response]
{
  "workspaceId": "wK4s8aP2",
  "emails": ["ada@example.com"]
}
```
