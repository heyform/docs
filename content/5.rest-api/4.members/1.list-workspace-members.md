---
title: "List workspace members"
description: "List the users and their roles in a workspace."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/workspaces/{workspaceId}/members"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `members:read` scope.
::

## Path parameters

::field{name="workspaceId" type="string" :required="true"}
Workspace ID. See [TeamModel][workspace-model].
::

## Response

**200** · `application/json`

Source model: [TeamMemberModel][member-model].

Returns an array with the following properties on each item.

| Field | Type | Description |
| --- | --- | --- |
| `userId` | `string` | User ID. |
| `role` | `integer` | Workspace role. `0` is owner, `1` admin, `2` collaborator, and `3` member. See [TeamRoleEnum][member-model]. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/workspaces/${WORKSPACE_ID}/members" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [200 response]
[
  {
    "userId": "507f1f77bcf86cd799439013",
    "role": 2
  }
]
```
