---
title: "Rename a form"
description: "Change the display name of a form."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/forms/{formId}"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

::field{name="name" type="string" :required="true"}
Display name, 1–100 characters after trimming.
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "Product feedback"
}'
```

```json [200 response]
{
  "id": "fE7D2aK4",
  "name": "Product feedback"
}
```
