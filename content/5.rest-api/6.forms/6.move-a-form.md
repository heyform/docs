---
title: "Move a form"
description: "Move a form to another project in the same workspace. The key must have write access to both projects."
apiReference: true
---

::api-reference{method="POST" path="/api/v1/forms/{formId}/move"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

::field{name="targetProjectId" type="string" :required="true"}
Destination project in the same workspace. See [ProjectModel][project-model].
::

## Response

**201** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `projectId` | `string` | Project ID. |
| `workspaceId` | `string` | Workspace ID. |

#examples

```bash [cURL]
curl --fail-with-body --request POST \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/move" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "targetProjectId": "pT9L3mK1"
}'
```

```json [201 response]
{
  "id": "fE7D2aK4",
  "projectId": "pT9L3mK1",
  "workspaceId": "wK4s8aP2"
}
```
