---
title: "Duplicate a form"
description: "Create an inactive copy in the source project. Submissions and the form password are excluded from the copy."
apiReference: true
---

::api-reference{method="POST" path="/api/v1/forms/{formId}/duplicate"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

::field{name="name" type="string" :required="true"}
Display name, 1–100 characters after trimming.
::

## Response

**201** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |
| `projectId` | `string` | Project ID. |
| `workspaceId` | `string` | Workspace ID. |
| `active` | `boolean` | Whether the form accepts responses. |

#examples

```bash [cURL]
curl --fail-with-body --request POST \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/duplicate" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "Feedback copy"
}'
```

```json [201 response]
{
  "id": "fC3Y8bN5",
  "name": "Feedback copy",
  "projectId": "pJ5Q7dR2",
  "workspaceId": "wK4s8aP2",
  "active": false
}
```
