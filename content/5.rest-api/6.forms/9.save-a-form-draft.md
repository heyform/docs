---
title: "Save a form draft"
description: "Save the editable questions and branching logic. The published form is unaffected."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/forms/{formId}/drafts"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

::field{name="version" type="integer" :required="true"}
Current draft version, returned by [Get a form](/rest-api/forms/get-a-form) or [Save a form draft](/rest-api/forms/save-a-form-draft). A stale version returns `409`.
::

::field{name="drafts" type="FormField[]" :required="true"}
Complete question and ending array. See [FormField][field-model], [FieldKindEnum][field-kinds], and [navigation validation][draft-validation].
::

::field{name="logics" type="Logic[]"}
Replacement branching rules. Use `[]` to clear them. When omitted, HeyForm uses existing draft logic or falls back to published logic. See [Logic][logic-model].
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `drafts` | `array` | Sanitized editable questions and endings. See [FormField][field-model]. |
| `version` | `integer` | Current draft version. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/drafts" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "version": 0,
  "drafts": [
    {
      "id": "question1",
      "kind": "short_text",
      "title": [
        "What should we improve?"
      ],
      "validations": {
        "required": true
      }
    },
    {
      "id": "thanks1",
      "kind": "thank_you",
      "title": [
        "Thanks!"
      ]
    }
  ],
  "logics": []
}'
```
