---
title: "Update form settings"
description: "Update one or more supported settings. Omitted settings are kept."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/forms/{formId}/settings"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

Send at least one field. See [FormSettings][settings-model] and the [REST validation rules][settings-validation].

::field{name="enableExpirationDate" type="boolean"}
Enable the form opening and closing schedule.
::

::field{name="enableTimeLimit" type="boolean"}
Enable the time limit for completing the form.
::

::field{name="filterSpam" type="boolean"}
Enable spam filtering.
::

::field{name="generatePseudonymId" type="boolean"}
Assign a pseudonym ID to submissions.
::

::field{name="enableQuotaLimit" type="boolean"}
Enable the response quota.
::

::field{name="enableIpLimit" type="boolean"}
Enable submission limits per IP address.
::

::field{name="displayIpAddress" type="boolean"}
Make submission IP addresses visible where supported.
::

::field{name="enableProgress" type="boolean"}
Show respondent progress.
::

::field{name="enableQuestionList" type="boolean"}
Show the question list.
::

::field{name="enableNavigationArrows" type="boolean"}
Show navigation arrows.
::

::field{name="openLinksInNewTab" type="boolean"}
Open links in a new tab.
::

::field{name="enableClosedMessage" type="boolean"}
Show a custom message for a closed form.
::

::field{name="allowArchive" type="boolean"}
Allow archiving submissions.
::

::field{name="requirePassword" type="boolean"}
Require a password. Supply `password` here if the form has no saved password.
::

::field{name="enableEmailNotification" type="boolean"}
Enable email notifications.
::

::field{name="redirectOnCompletion" type="boolean"}
Redirect the respondent after completion.
::

::field{name="enabledAt" type="integer ≥ 0"}
Opening time as Unix seconds.
::

::field{name="closedAt" type="integer ≥ 0"}
Closing time as Unix seconds.
::

::field{name="timeLimit" type="integer ≥ 0"}
Completion time limit in seconds.
::

::field{name="ipLimitTime" type="integer ≥ 0"}
Per-IP limit window in seconds.
::

::field{name="redirectDelay" type="integer ≥ 0"}
Delay before redirecting on completion.
::

::field{name="quotaLimit" type="integer ≥ 1"}
Maximum number of responses.
::

::field{name="ipLimitCount" type="integer ≥ 1"}
Maximum submissions per IP in the configured window.
::

::field{name="expirationTimeZone" type="string"}
Time zone for the opening and closing schedule.
::

::field{name="locale" type="string"}
Form interface locale, for example `en`.
::

::field{name="closedFormTitle" type="string"}
Heading for the closed form.
::

::field{name="closedFormDescription" type="string"}
Description for the closed form.
::

::field{name="metaTitle" type="string"}
Page title used in metadata.
::

::field{name="metaDescription" type="string"}
Page description used in metadata.
::

::field{name="redirectUrl" type="string"}
Completion redirect. Use an HTTP or HTTPS URL.
::

::field{name="metaOGImageUrl" type="string"}
Social preview image. Use an HTTP or HTTPS URL.
::

::field{name="password" type="string"}
Form password, 1–72 characters.
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `updated` | `boolean` | Whether the update succeeded. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/settings" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "enableProgress": true,
  "locale": "en",
  "redirectOnCompletion": true,
  "redirectUrl": "https://example.com/thanks"
}'
```

```json [200 response]
{
  "id": "fE7D2aK4",
  "updated": true
}
```
