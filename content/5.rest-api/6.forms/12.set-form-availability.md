---
title: "Set form availability"
description: "Open or close a form for responses. The form must have been published before you can open it."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/forms/{formId}/availability"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

Send only the `active` property.

::field{name="active" type="boolean" :required="true"}
Set to `true` to accept responses or `false` to close the form.
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `active` | `boolean` | Whether the form accepts responses. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/availability" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "active": true
}'
```

```json [200 response]
{
  "id": "fE7D2aK4",
  "active": true
}
```
