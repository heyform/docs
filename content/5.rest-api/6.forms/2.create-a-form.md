---
title: "Create a form"
description: "Create an unpublished form with a starter draft."
apiReference: true
---

::api-reference{method="POST" path="/api/v1/projects/{projectId}/forms"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="projectId" type="string" :required="true"}
Project ID. See [ProjectModel][project-model].
::

## Request body

`application/json`

::field{name="name" type="string" :required="true"}
Display name, 1–100 characters after trimming.
::

## Response

**201** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |
| `projectId` | `string` | Project ID. |
| `workspaceId` | `string` | Workspace ID. |

#examples

```bash [cURL]
curl --fail-with-body --request POST \
  --url "${HEYFORM_URL}/api/v1/projects/${PROJECT_ID}/forms" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "Customer feedback"
}'
```

```json [201 response]
{
  "id": "fE7D2aK4",
  "name": "Customer feedback",
  "projectId": "pJ5Q7dR2",
  "workspaceId": "wK4s8aP2"
}
```
