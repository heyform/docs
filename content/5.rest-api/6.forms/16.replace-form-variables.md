---
title: "Replace form variables"
description: "Replace the form’s variables. Send an empty array to clear them."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/forms/{formId}/variables"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

::field{name="variables" type="Variable[]" :required="true"}
Up to 200 objects with `id`, `name`, `kind`, and `value`. IDs must be unique and contain 1–128 letters, digits, underscores, or hyphens. Names contain 1–100 characters after trimming. Set `kind` to `string` or `number` and supply a value of that type. See [Variable][variable-model].
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `variables` | `array` | Variables associated with the resource. See [Variable][variable-model]. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/variables" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "variables": [
    {
      "id": "score1",
      "name": "score",
      "kind": "number",
      "value": 0
    }
  ]
}'
```

```json [200 response]
{
  "id": "fE7D2aK4",
  "variables": [
    {
      "id": "score1",
      "name": "score",
      "kind": "number",
      "value": 0
    }
  ]
}
```
