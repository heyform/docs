---
title: "Get a workspace"
description: "Retrieve the name and owner of a workspace."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/workspaces/{workspaceId}"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/rest-api#create-an-api-key) that has the `workspaces:read` scope.
::

## Path parameters

::field{name="workspaceId" type="string" :required="true"}
Workspace ID. See [TeamModel][workspace-model].
::

## Response

**200** · `application/json`

Source model: [TeamModel][workspace-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |
| `ownerId` | `string` | ID of the user who owns the resource. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/workspaces/${WORKSPACE_ID}" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [200 response]
{
  "id": "wK4s8aP2",
  "name": "Research",
  "ownerId": "507f1f77bcf86cd799439012"
}
```
