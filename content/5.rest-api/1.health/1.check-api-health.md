---
title: "Check API health"
description: "Confirm that your bearer key works and identify the API version."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/health"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with any valid [API key](/rest-api#create-an-api-key).
::

## Response

**200** · `application/json`

| Field | Type | Description |
| --- | --- | --- |
| `status` | `string` | `ok` when the API is reachable and the key is valid. |
| `version` | `string` | API version. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/health" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [200 response]
{
  "status": "ok",
  "version": "v1"
}
```
