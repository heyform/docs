---
title: "List workspaces"
description: "List workspaces accessible to the current API key."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/workspaces"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `workspaces:read` scope.
::

## Response

**200** · `application/json`

Source model: [TeamModel][workspace-model].

Returns an array with the following properties on each item.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |
| `ownerId` | `string` | ID of the user who owns the resource. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/workspaces" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [200 response]
[
  {
    "id": "wK4s8aP2",
    "name": "Research",
    "ownerId": "507f1f77bcf86cd799439012"
  }
]
```
