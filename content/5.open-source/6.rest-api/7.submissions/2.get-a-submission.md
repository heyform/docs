---
title: "Get a submission"
description: "Retrieve a public submission with its answers and captured values."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/forms/{formId}/submissions/{submissionId}"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `submissions:read` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

::field{name="submissionId" type="string" :required="true"}
The 24-character hexadecimal submission ID. See [SubmissionModel][submission-model].
::

## Response

**200** · `application/json`

Source model: [SubmissionModel][submission-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `formId` | `string` | ID of the form. |
| `title` | `string` | Submission title. |
| `category` | `string` | Submission category. See [SubmissionCategoryEnum][submission-category]. |
| `answers` | `array` | Answers collected for the submission. See [Answer][answer-model]. |
| `hiddenFields` | `array` | Hidden field values captured for the submission. See [HiddenFieldAnswer][answer-model]. |
| `variables` | `array` | Variables associated with the resource. See [Variable][variable-model]. |
| `startAt` | `integer` | When the respondent started, as Unix seconds, if recorded. |
| `endAt` | `integer` | When the respondent completed the form, as Unix seconds, if recorded. |
| `pseudonymId` | `string` | Assigned pseudonym ID, if enabled for this submission. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/submissions/${SUBMISSION_ID}" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```
