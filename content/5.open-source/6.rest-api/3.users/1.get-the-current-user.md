---
title: "Get the current user"
description: "Retrieve the user who owns this API key."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/users/me"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key). No scope is required.
::

## Response

**200** · `application/json`

Source model: [UserModel][user-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | User ID. |
| `name` | `string` | Display name. |
| `email` | `string` | Email address. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/users/me" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [200 response]
{
  "id": "507f1f77bcf86cd799439013",
  "name": "Ada Lovelace",
  "email": "ada@example.com"
}
```
