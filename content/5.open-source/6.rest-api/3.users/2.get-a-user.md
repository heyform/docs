---
title: "Get a user"
description: "Retrieve a user by ID. The user must belong to a workspace accessible to this key."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/users/{userId}"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `users:read` scope.
::

## Path parameters

::field{name="userId" type="string" :required="true"}
User ID. See [UserModel][user-model].
::

## Response

**200** · `application/json`

Source model: [UserModel][user-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |
| `email` | `string` | Email address. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/users/${USER_ID}" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [200 response]
{
  "id": "507f1f77bcf86cd799439013",
  "name": "Ada Lovelace",
  "email": "ada@example.com"
}
```
