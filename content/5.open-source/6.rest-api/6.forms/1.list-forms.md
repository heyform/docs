---
title: "List forms"
description: "List the forms in a project, excluding forms in the trash."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/projects/{projectId}/forms"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `forms:read` scope.
::

## Path parameters

::field{name="projectId" type="string" :required="true"}
Project ID. See [ProjectModel][project-model].
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

Returns an array with the following properties on each item.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |
| `version` | `integer` | Current draft version. |
| `publishedAt` | `integer` | Time of first publication as Unix seconds. `0` means the form has never been published. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/projects/${PROJECT_ID}/forms" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [200 response]
[
  {
    "id": "fE7D2aK4",
    "name": "Customer feedback",
    "version": 0,
    "publishedAt": 0
  }
]
```
