---
title: "Update the form theme"
description: "Replace the theme object and optionally update the logo or favicon."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/forms/{formId}/theme"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

::field{name="theme" type="object" :required="true"}
Replacement [theme object][theme-model]. Supported string keys are `fontFamily`, `questionTextColor`, `answerTextColor`, `buttonBackground`, `buttonTextColor`, `backgroundColor`, `backgroundImage`, and `customCSS`. `backgroundBrightness` is a number between −100 and 100. CSS values are validated.
::

::field{name="logo" type="string or null"}
Logo URL using HTTP or HTTPS. Use `null` to clear it.
::

::field{name="favicon" type="string or null"}
Favicon URL using HTTP or HTTPS. Use `null` to clear it.
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `updated` | `boolean` | Whether the update succeeded. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/theme" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "theme": {
    "fontFamily": "sans-serif",
    "backgroundColor": "#ffffff",
    "backgroundBrightness": 0
  },
  "logo": null
}'
```

```json [200 response]
{
  "id": "fE7D2aK4",
  "updated": true
}
```
