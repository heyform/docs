---
title: "Get a form"
description: "Retrieve the published fields, editable drafts, version, and current form state."
apiReference: true
---

::api-reference{method="GET" path="/api/v1/forms/{formId}"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `forms:read` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |
| `workspaceId` | `string` | Workspace ID. |
| `projectId` | `string` | Project ID. |
| `fields` | `array` | Published questions and endings. See [FormField][field-model]. |
| `drafts` | `array` | Sanitized editable questions and endings. See [FormField][field-model]. |
| `hiddenFields` | `array` | Hidden fields. See [HiddenField][hidden-field-model]. |
| `variables` | `array` | Variables associated with the resource. See [Variable][variable-model]. |
| `logics` | `array` | Published branching rules. See [Logic][logic-model]. |
| `draftLogics` | `array` | Editable branching rules, when present. See [Logic][logic-model]. |
| `themeSettings` | `object` | Theme, logo, and favicon settings, when present. See [ThemeSettings][theme-model]. |
| `status` | `integer` | `1` for a normal form and `2` for a form in the trash. See [FormStatusEnum][form-enums]. |
| `active` | `boolean` | Whether the form accepts responses. |
| `version` | `integer` | Current draft version. |
| `publishedAt` | `integer` | Time of first publication as Unix seconds. `0` means the form has never been published. |

#examples

```bash [cURL]
curl --fail-with-body --request GET \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```
