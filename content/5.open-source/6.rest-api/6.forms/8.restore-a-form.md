---
title: "Restore a form"
description: "Move a form out of the trash. The restored form starts inactive."
apiReference: true
---

::api-reference{method="POST" path="/api/v1/forms/{formId}/restore"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Response

**201** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `restored` | `boolean` | Whether the form was restored. |

#examples

```bash [cURL]
curl --fail-with-body --request POST \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/restore" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}"
```

```json [201 response]
{
  "id": "fE7D2aK4",
  "restored": true
}
```
