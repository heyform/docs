---
title: "Replace hidden fields"
description: "Replace the form’s hidden fields. Send an empty array to clear them."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/forms/{formId}/hidden-fields"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `forms:write` scope.
::

## Path parameters

::field{name="formId" type="string" :required="true"}
Form ID. See [FormModel][form-model].
::

## Request body

`application/json`

::field{name="hiddenFields" type="HiddenField[]" :required="true"}
Up to 200 objects with a unique `id` and unique `name`. IDs contain 1–128 letters, digits, underscores, or hyphens. Names contain 1–100 characters after trimming. See [HiddenField][hidden-field-model].
::

## Response

**200** · `application/json`

Source model: [FormModel][form-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `hiddenFields` | `array` | Hidden fields. See [HiddenField][hidden-field-model]. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/forms/${FORM_ID}/hidden-fields" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "hiddenFields": [
    {
      "id": "campaign1",
      "name": "campaign"
    }
  ]
}'
```

```json [200 response]
{
  "id": "fE7D2aK4",
  "hiddenFields": [
    {
      "id": "campaign1",
      "name": "campaign"
    }
  ]
}
```
