---
title: "Create a project"
description: "Create a project in the workspace. With an account key, the key owner becomes the project owner."
apiReference: true
---

::api-reference{method="POST" path="/api/v1/workspaces/{workspaceId}/projects"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `projects:write` scope.
::

## Path parameters

::field{name="workspaceId" type="string" :required="true"}
Workspace ID. See [TeamModel][workspace-model].
::

## Request body

`application/json`

::field{name="name" type="string" :required="true"}
Display name, 1–100 characters after trimming.
::

## Response

**201** · `application/json`

Source model: [ProjectModel][project-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |
| `workspaceId` | `string` | Workspace ID. |
| `ownerId` | `string` | ID of the user who owns the resource. |

#examples

```bash [cURL]
curl --fail-with-body --request POST \
  --url "${HEYFORM_URL}/api/v1/workspaces/${WORKSPACE_ID}/projects" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "Customer surveys"
}'
```

```json [201 response]
{
  "id": "pJ5Q7dR2",
  "name": "Customer surveys",
  "workspaceId": "wK4s8aP2",
  "ownerId": "507f1f77bcf86cd799439012"
}
```
