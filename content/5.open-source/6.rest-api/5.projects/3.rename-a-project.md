---
title: "Rename a project"
description: "Change the name of a project you can access."
apiReference: true
---

::api-reference{method="PATCH" path="/api/v1/projects/{projectId}"}

## Authorization

::field{name="Authorization" type="string · header" :required="true"}
Send `Bearer <token>` with an [account API key](/open-source/rest-api#create-an-api-key) that has the `projects:write` scope.
::

## Path parameters

::field{name="projectId" type="string" :required="true"}
Project ID. See [ProjectModel][project-model].
::

## Request body

`application/json`

::field{name="name" type="string" :required="true"}
Display name, 1–100 characters after trimming.
::

## Response

**200** · `application/json`

Source model: [ProjectModel][project-model].

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | ID returned by the operation. |
| `name` | `string` | Display name. |

#examples

```bash [cURL]
curl --fail-with-body --request PATCH \
  --url "${HEYFORM_URL}/api/v1/projects/${PROJECT_ID}" \
  --header "Authorization: Bearer ${HEYFORM_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "Feedback surveys"
}'
```

```json [200 response]
{
  "id": "pJ5Q7dR2",
  "name": "Feedback surveys"
}
```
